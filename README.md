# updown - 轻量级 URL 状态监控系统

一个开箱即用的 PHP 应用，用于监测多个 HTTP/HTTPS 服务的可用性与响应时间。无需数据库，基于 JSON 存储，支持并行检测、可视化仪表盘和密码保护的后台管理。

特性

并行检测多个 URL 的 HTTP 状态码与响应时间
简洁仪表盘：卡片式布局，状态一目了然（绿/红标识）（红标识目前有bug）
后台管理：增删改查监测目标，设置全局超时与自动刷新间隔
自动刷新：访问前端页面时按间隔自动触发检测（无需系统 cron）（也可使用伪cron）（自动刷新在某些浏览器无法使用）
手动刷新：一键立即检测所有服务
表格排序：按状态、响应时间等排序
数据存储：纯 JSON 文件，无需 MySQL（后期使用MySQL）
轻量依赖：仅需 PHP ≥7.4 与 cURL 扩展

快速开始

1. 将所有文件上传至 PHP 网站目录
2. 确保目录可写（自动生成 data.json）
3. 访问 index.php 查看监控面板
4. 访问 admin.php 管理目标（默认密码 admin123，可在 config.php 修改）

技术栈

 PHP 7.4+ (cURL, JSON)
 HTML5/CSS3 (Flex/Grid, 响应式)
 原生 JavaScript (无框架)
